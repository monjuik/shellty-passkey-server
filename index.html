Operations

From download to running.

Create DB
Write config.json
Start passkey-server
Call the API
./passkey-server \
  --config=config.json \
  --database-dsn="$DATABASE_DSN" \
  --tls-cert=server.crt \
  --tls-key=server.key \
  --client-ca=client-ca.crt
